# Embedding Compressor HPO (Hyperparameter Optimization)

A deep learning optimization engine built to find optimal architecture and compression configurations for high-dimensional image embeddings extracted via a DINOv2 backbone.

### Architecture & Technical Highlights
* **Neural Network Architecture:** Combines a frozen **DINOv2** vision backbone with two custom learnable compression layers:
  1. **Dimensionality Reduction Layer:** A configurable Linear compression layer reducing vector channel dimension.
  2. **Cross-Attention Sequence Aggregator:** A custom PyTorch module leveraging Cross-Attention mechanisms to compress a variable sequence of image embeddings per listing (e.g., 20 raw gallery images) into a fixed, highly dense set of target sequence embeddings (e.g., 8 tokens).
* **Automated Hyperparameter Tuning:** Integrates **Optuna** with **MLflow** experiment tracking to run automated search studies across:
  * **Embedding Dimension Size:** Target output units for the linear projection layer.
  * **Sequence Length Target:** Optimal number of output latent tokens generated by the Cross-Attention layer for multi-image represesntation.
* **Experiment Tracking:** Logs metric trajectories, trial parameters, loss curves, and artifact checkpoints directly to MLflow.
